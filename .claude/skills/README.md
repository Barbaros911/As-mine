# Compétences installées

Ces dossiers ne sont pas du code du site : ils apprennent à Claude des façons
de faire, pour t'aider sur As-mine, les sites de `sites/`, et ton activité en
général. Rien ici n'est publié en ligne — le site publié ne prend que les
fichiers listés dans `.github/workflows/pages.yml`.

Tu n'as rien à retenir : décris ce que tu veux en français normal, Claude
choisit tout seul la compétence qui correspond.

## Pour ton activité (créer et vendre des sites vitrines)

| Compétence | Demande-lui... |
|---|---|
| `domain-name-brainstormer` | « trouve-moi un nom de domaine pour ce site » |
| `lead-research-assistant` | « trouve-moi des commerces à démarcher dans tel secteur » |
| `content-research-writer` | « améliore les textes de cette page » |
| `theme-factory` | « change les couleurs de cette page » |
| `competitive-ads-extractor` | « regarde ce que font les concurrents de ce client » |
| `brand-guidelines` | garde une identité visuelle cohérente entre les pages |
| `image-enhancer` | « cette photo du client est floue, améliore-la » |
| `webapp-testing` | vérifie qu'un site marche vraiment, avant de le publier |
| `artifacts-builder` | pour une démo plus poussée qu'une simple page |
| `canvas-design` | « fais-moi une affiche/visuel pour les réseaux du client » |

## Ce qui n'a pas été installé, et pourquoi

Le dépôt source (`ComposioHQ/awesome-claude-skills`) contient environ 900
autres compétences, presque toutes du même genre : une par application
(Gmail, Instagram, Shopify, HubSpot, WhatsApp Business...). Elles ne
fonctionnent qu'après avoir créé un compte gratuit chez Composio et donné une
clé d'accès à Claude — c'est ce qui a été exclu ici, comme demandé. Si un jour
tu veux que Claude poste automatiquement sur les réseaux d'un client ou
envoie des emails à ta place, on branche ce compte à ce moment-là.
