# Sécurité ELA Transfer

Les informations de sécurité, identifiants, mots de passe, jetons et clés privées ne doivent jamais être publiés dans une issue GitHub publique.

Toute vulnérabilité doit être traitée comme privée jusqu'à correction. Les contrôles d'accès doivent être réalisés côté serveur et base de données ; les contrôles JavaScript ne constituent qu'une aide d'interface.
