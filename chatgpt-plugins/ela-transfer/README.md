# ELA Transfer ChatGPT Plugin

A skills-only plugin for safe work on the ELA Transfer project.

Included skills:
- ela-project-manager — coordinates scoped project work
- planner-architect — plans changes and architectural impact
- github-reviewer — reviews branches and pull requests
- site-qa — validates customer, hotel/reception and admin experiences
- test-guide — designs focused regression tests
- security-guard — checks security and sensitive-data risks
- build-troubleshooter — diagnoses build/CI failures
- deployment-guard — gates production-changing actions
- ela-rules — applies stable project conventions

This plugin does not contain credentials, hooks, executable install scripts, MCP servers, or deployment automation. External actions remain subject to the permissions of connected ChatGPT apps such as GitHub.
