# ELA Transfer ChatGPT Plugin

A skills-only plugin for safe work on the ELA Transfer project.

Included skills:
- ela-project-manager
- github-reviewer
- site-qa
- security-guard
- deployment-guard
- ela-rules

This plugin does not contain credentials, hooks, executable install scripts, MCP servers, or deployment automation. External actions remain subject to the permissions of connected ChatGPT apps such as GitHub.
